## I8 reviewed: the nav container follows the layout

- The six component-less pages P1.1 found are each a `site-frontpage`
  component's index on `:page-layout: without_menu`, and the UI bundle
  renders the nav container only on the `with_menu`, `404` and `category`
  layouts. I8 now states that condition, with the UI bundle as its proof.
- The maintainer settled what the `antora` Extract hook does with such a page:
  the component is read from the URL, and the version is left absent
  (`../../design/roadmap-P2-extractor-inbox.md`). Recording no component was
  rejected because D19 could then never resolve an xref into these
  components, and a partial CI build leaves all of them unresolved. Deriving
  the version from what is left of the URL was rejected because no versioned
  component uses the layout. If one ever does, the miss shows up as an
  unresolved reference, not a wrong one, and it fights I5's `latest` aliasing.
  D19 keeps describing the nav container until P2 builds the fallback.
