## A review crawl is three tasks (M21)

8.20 reads the digest's two-run sections, which need a database holding two
crawls whose runs differ by the site and not by the config, as 8.1's and
8.14's do (8.8.1's notes). `mise run crawl` copies the newest finished en-US
crawl's database into `runs/en-us-<YYYYMMDD-HHMM>/` and launches the crawl
into the copy, detached, so the digest's default `--from` is the copied run;
`mise run digest` and `mise run serve` write and serve it. The first copies
`runs/p8.14-en-us-20261024-1322/en-us.duckdb`. `scripts/review.py` says what
each leaves in the directory.
