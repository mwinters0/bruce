# P8.8.3 — An empty two-run section left out: notes

Earned by 8.20's sixth finding. `compared::shown` decides both sections and
the header's links to them, so a link never points at a section that is not
there. A digest with no comparison has neither: its sub-title, "No earlier
run to compare with", is the one place that says so, the sections' own
sentences for that case being gone. A section that is shown always lists
something, so its "None." is gone too.
