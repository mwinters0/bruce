{% block guide_doubled_slash %} {% if judged.doubled_slash %}

{{ question("doubled-slash") }}

Někdy je stránka B v pořádku, když se na ni dostanete správnou cestou, ale stránka A na ni odkazuje tak, že přidá lomítko navíc, např. example.com/foo//page_B/ nebo example.com/foo/page_B//, nebo odkazuje na adresu, která přesměrovává na takovou.

Pokud se ze stránky A na B dostanete touto cestou, stránka B bude fungovat, ale všechny její relativní odkazy (../../blah) jsou kvůli lomítku navíc v cestě nefunkční. Nepočítají se proti stránce B, protože na ní není nic špatně: problém je na stránce A. Proto je odkaz stránky A uveden jako nefunkční s důvodem doubled_slash a {% if judged.reach == "full" %}odkazy na stránce B, které lomítko navíc rozbije, i odkazy na každé další stránce s adresou se zdvojeným lomítkem, kam relativní odkazy ze stránky B vedou dál, se počítají u stránky A jako „nefunkční kvůli němu“{% elif judged.reach == "immediate" %}odkazy na stránce B, které lomítko navíc rozbije, se počítají u stránky A jako „nefunkční kvůli němu“, ne však odkazy stránek, kam relativní odkazy ze stránky B vedou dál{% else %}odkazy na stránce B, které lomítko navíc rozbije, se nepočítají nikde, protože tento přehled je nastaven tak, že vinu nese jen odkaz stránky A{% endif %}.

{% endif %} {% endblock %} {% block guide_pedantic %} {% if judged.pedantic_trailing_slash %}

{{ question("pedantic") }}

Lidé obvykle píší adresy jako example.com/foo, ale technicky správný tvar je example.com/foo/: všimněte si koncového lomítka. Pro většinu webových serverů jsou to ve skutečnosti dvě různé stránky, a když navštívíte první, server ochotně sdělí vašemu prohlížeči: „Hej, tady nic není, je to na example.com/foo/.“ Prohlížeč tak musí poslat druhý požadavek.

Má se „špatná“ adresa počítat jako nefunkční, když čtenář nakonec skončí na správném místě? Dá se o tom diskutovat, ale rozhodně je to méně naléhavé než skutečně nefunkční odkaz (třeba 404). Nepočítají se jako nefunkční: {% if pedantic == "pedantic" %}jsou v části Údržba mezi přesměrovanými odkazy, označené jako pedantní kroužkem, za ostatními přesměrováními{% elif pedantic == "attention" %}jsou v části Údržba mezi přesměrovanými odkazy, označené jako pozornost oranžovou tečkou, za ostatními přesměrováními{% elif pedantic == "broken" %}jsou v části Údržba mezi přesměrovanými odkazy, označené jako nefunkční červenou tečkou, za ostatními přesměrováními{% else %}tento přehled je nastaven tak, že je nepovažuje za nález, takže je nevypisuje{% endif %}.
