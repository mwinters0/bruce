Allowed Licenses

This page lists the all the licenses that are allowed for use in Fedora. If a license is marked as allowed, it is allowed for any use. If a license is marked as allowed-fonts, allowed-content, allowed-documentation, or allowed-firmware, then it is allowed only for certain categories of material as described in License Approval. This information is generated from data maintained in the Fedora License Data repository. xref:allowed-licenses.adoc contains the same information, but broken out to different tables for each category of allowed.
